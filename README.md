# XR30 NAND OpenWrt 闭源驱动固件

## 📋 支持设备
- ✅ **XR30 NAND 版**

## ⚡ 核心特性
- **基于 OpenWrt 25.12：6.12 内核**
- **闭源 MTK 驱动：wed / hnat 硬件加速**
- **集成 nginx + LuCI**
- **中继增强**
- **自建源支持**

## 📦 默认插件
- luci-app-socat
- luci-app-samba4
- luci-theme-m3e
- luci-app-ttyd
- luci-app-diskman
